清洗与污染控制：看不见的敌人

一颗纳米级的微粒就能废掉一颗裸片，一个钠离子就能让阈值电压漂移。清洗是全流程出现次数最多的步骤——它不生产任何结构，但直接决定良率。

01洗什么，用什么洗

表面上其实有四类脏东西，各自要用不同的化学药液。选一种洗法，看哪几类被带走。

SC1（氨水 + 双氧水 + 水）：轻微腐蚀表面，让微粒「托离」表面再被冲走，同时去除有机物。是 RCA 清洗的第一步。

为什么光洗不干净：微粒不是「粘」在表面，而是靠静电和范德华力贴着。所以要先用化学药液把表面轻微腐蚀一点，让颗粒失去附着的基底，再用水冲走。

02RCA 清洗：1960 年代的方法，今天还在用

配方主要成分去除什么
SC1氨水 + 双氧水 + 水微粒、有机物
SC2盐酸 + 双氧水 + 水金属污染（钠、铁、铜…）
DHF稀释氢氟酸薄氧化层（含原生氧化层）
SPM硫酸 + 双氧水有机物、光刻胶残留

RCA 是最早发表这套方法的实验室名字，不是某种化学品。实际产线会在它基础上加超声、兆声、单片旋转等手法。

03批式还是单片

批式湿法清洗槽

整批晶圆依序浸入一排化学槽与清水槽，像洗车流水线。产能高、成本低；缺点是片与片之间可能互相带污染，槽液也会随使用变化。

单片旋转清洗

一次一片，边转边喷。药液新鲜、控制精准、无交叉污染，先进工艺越来越常用；代价是产能低、药液用量大。

水也是耗材：清洗用的是超纯水（UPW），几乎不含离子、微粒和细菌。晶圆厂每天用掉大量超纯水，是厂务的大项。

04洗干净之后：Q-Time 与交叉污染

Q-Time：干净会过期

清洗后的表面会重新长出原生氧化层、吸附空气中的污染物。所以两站之间有等待上限，超时就要重洗。系统会自动算、自动挡。

铜不能回前段

铜在硅里扩散极快，微量进入晶体管区就会漏电。铜区的设备、晶圆盒、手套都要与前段严格分开，靠标签和系统等级卡住。

背面也要洗：背面一颗微粒会把晶圆局部顶高，曝光时那一块就失焦；微粒还会留在设备上传给下一片。所以清洗和检查不能只看正面。

＋原文里的名词与现场经验

以下内容逐条取自原书，保留「定义 / 现场用法 / 常见混淆」与「情境 / 做法 / 为什么」的原始结构。

名词RCA 清洗（RCA Clean）

定义
以 SC1、SC2 为核心的标准晶圆清洗流程。
现场用法
「炉管前要先过一道 RCA。」
相关名词
SC1、SC2、DHF、炉前清洗
常见混淆
RCA 是最早发表这套方法的实验室名称，不是某种化学品。

名词Q-Time（Queue Time，等待时间限制）

定义
两个工艺步骤之间允许等待的最长时间。
现场用法
「这批 Q-Time 快到了，先跑它」「Q-Time 超过了，要重洗」。
相关名词
Hold、返工、派工
常见混淆
Q-Time 不是工艺本身花的时间，而是「两站之间可以等多久」。它也不只用在清洗，例如铜 CMP 之后到铺上覆盖层之间，同样有 Q-Time 限制。

Know-how接触过铜的东西，不能回到前段

情境
晶圆进入金属导线工艺后，开始接触铜。
做法
工厂会把设备和晶圆盒分成不同的污染等级，常用颜色或标签区分。系统也会检查晶圆盒和设备的等级是否相符，不符就禁止进设备。
为什么
微量的铜一旦被带进前段设备，就会污染之后经过那台设备的所有晶圆。
没做会怎样
大范围的晶圆受到铜污染，晶体管漏电，良率大幅下降，而且很难追查源头。

Know-how晶圆背面也要干净

情境
晶圆背面沾了一颗微粒。
做法
清洗和检查不能只顾正面，背面的微粒和污染同样要控制。
为什么
曝光时晶圆平贴在设备上，背面的微粒会把晶圆局部顶高，造成失焦；微粒还可能留在设备上，传给下一片晶圆。
没做会怎样
同一个位置反复出现失焦的缺陷，而且一台设备可能污染许多批晶圆。

本章重点

  1. 四类污染：微粒、金属、有机物、原生氧化层，各有对应药液。
  2. RCA 清洗（SC1 / SC2）是基准配方，DHF 去氧化层，SPM 去有机物。
  3. 批式产能高但有交叉污染风险；单片精准、先进工艺更常用。
  4. Q-Time 限制清洗后的等待时间，超时要重洗。
  5. 铜必须与前段隔离，否则会大范围污染。
